# Keyboard, Xbox and PlayStation controls

Connect the controller using USB or pair it through the operating system’s Bluetooth settings. Open the game and press any controller button once so the browser can detect it. The game displays the detected controller family. Supported controllers must expose the browser’s **standard** Gamepad mapping. Xbox, DualShock 4 and DualSense support depends on the browser and operating system; physical devices have not been tested in this session.

| Action | Keyboard | Xbox | PlayStation |
|---|---|---|---|
| Move | WASD | Left stick / D-pad | Left stick / D-pad |
| Punch | J | X | Square |
| Kick | K | B | Circle |
| Dash | Space | A | Cross |
| Grab / drop / collect clue | E | Y | Triangle |
| Hold block | I or L | LB or LT | L1 or L2 |
| Special | Q | RT | R2 |
| Case board | N | RB | R1 |
| Pause / resume | Escape | Menu / Start | Options |
| Confirm menu / briefing | Mouse / Enter | A | Cross |
| Return from dialog | Mouse | B | Circle |

In the menu, use up/down to focus controls. On fighter, rival and arena selectors, use D-pad left/right to change the selection. A/Cross activates a focused button. In the suspect puzzle, use up/down to choose a suspect, A/Cross to accuse, and Y/Triangle to review evidence.

Analog sticks use a dead zone to reject drift. Attacks trigger once per press, blocking remains held, diagonal speed is capped, and disconnecting clears controller movement and block input. XR controllers use the separate WebXR controls and are not treated as console gamepads. There is no local two-player controller mode yet; one-on-one mode is against AI.
